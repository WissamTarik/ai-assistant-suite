# 🤖 ChatGPT AI Assistant Clone

A modern, responsive, and **fully accessible** AI Chat Interface inspired by ChatGPT. Built with **React 18**, **TypeScript**, and **React Bootstrap**, featuring WCAG-compliant accessibility (a11y), multi-modal image attachment support, theme customization (Light/Dark/System), and chat export capabilities.

## ✨ Features

- **♿ Built-in Accessibility (a11y):** Formulated around WCAG guidelines with keyboard focus management, ARIA landmarks, screen reader status announcements (`aria-live`), and semantic HTML markup.
- **💬 Rich Chat Interface:** Interactive message history with real-time response indicator.
- **🖼️ Multi-Modal Support:** Attach image previews via file picker or clipboard paste.
- **🚀 Quick Starter Prompts:** Curated starter cards for quick conversation launches.
- **🌓 Adaptive Theme Engine:** Seamless switching between Light, Dark, and System preferred themes using Bootstrap CSS variables.
- **📥 Export Options:** Download chat logs as Markdown (`.md`), Plain Text (`.txt`), or PDF (`.pdf`).
- **📋 One-Click Share & Copy:** Share links and copy message contents directly to clipboard.
- **📱 Fully Mobile Responsive:** Sliding Offcanvas sidebar and mobile-friendly touch targets.
